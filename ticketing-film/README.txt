CARA MENJALANKAN (XAMPP)
1. Salin folder "ticketing" ke C:\xampp\htdocs\
2. Buka XAMPP Control Panel, jalankan Apache dan MySQL.
3. Buka http://localhost/phpmyadmin -> tab "Import" -> pilih file database.sql -> Go.
4. Buka http://localhost/ticketing/
